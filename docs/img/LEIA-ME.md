# Prints da landing page

Gerados por `npm run screenshots` — **não edite nem substitua à mão**.
Quando a interface mudar, rode o script de novo (ou dispare o workflow
`screenshots` pelo GitHub Actions) em vez de recortar imagem.

Os dados que aparecem neles são fictícios (`scripts/demo-library.mjs`):
artistas, álbuns, músicas e capas foram inventados para esta finalidade.
Nenhum metadado ou arte de obra real entra no material de divulgação.
